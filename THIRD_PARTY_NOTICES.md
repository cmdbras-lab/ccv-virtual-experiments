# Avisos de software de terceiros

Este projeto utiliza os seguintes componentes:

- **MediaPipe Hands**, Google — licença Apache-2.0.
- **Vite** — licença MIT, utilizado apenas para desenvolvimento e compilação.
- **TypeScript** — licença Apache-2.0, utilizado apenas para desenvolvimento e verificação.

Os ficheiros de modelos e execução do MediaPipe são distribuídos para permitir processamento local. Antes de uma redistribuição pública ou comercial, confirmar os textos integrais das licenças nas versões instaladas em `node_modules`.

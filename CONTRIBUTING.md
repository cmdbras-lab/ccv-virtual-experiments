# Contribuir

- `main` contém a versão estável.
- `develop` reúne alterações validadas para a próxima versão.
- Cada experiência ou correção deve usar uma branch própria.
- Antes de abrir um pull request, executar `npm ci`, `npm run check` e `npm run test:smoke`.
- Não incluir `node_modules`, `dist`, gravações da câmara, rankings locais ou dados pessoais.

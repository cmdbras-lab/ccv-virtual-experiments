# Publicação da versão 3.0.6.1

Este ficheiro regista o pedido explícito de compilação, validação, criação da GitHub Release e publicação da página de divulgação da versão 3.0.6.1.

A página deve apresentar as seis experiências, destacar o Duelo Gravitacional e consultar automaticamente a Release mais recente para os botões de download.

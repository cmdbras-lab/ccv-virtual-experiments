# Aviso de privacidade para colocar junto ao ecrã

## Ciência em Movimento

Esta instalação utiliza uma câmara para detetar a posição e os gestos de uma mão.

- As imagens são processadas localmente e não são gravadas.
- Não existe reconhecimento facial nem identificação de pessoas.
- Um sinal temporário de movimento pode ser usado apenas para apresentar o convite inicial.
- Não é captado som.
- O ranking utiliza apenas três iniciais escolhidas pelo participante.
- As pontuações ficam guardadas apenas no computador desta instalação.

Ao afastar-se do ecrã, a interação termina automaticamente.
